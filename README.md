# DataSensor OTA

Binarios de actualizacion por aire (OTA) del sensor DataSensor. Repo publico a proposito: solo firmware compilado (no sensible) + manifiesto, para descargar por HTTPS sin credenciales. El codigo fuente sigue en un repo privado.

- manifest.json — version disponible y URL del binario
- firmware.bin — imagen de la aplicacion (particion OTA)
